# IndicJevBench — Supported Languages

| Code | Script | Name | Example Sources | Notes |
|------|--------|------|-----------------|-------|
| `hi-Deva` | Devanagari | Hindi | MASSIVE, synthetic (UPI/e-commerce) | Primary Indic language; largest synthetic coverage |
| `hi-Latn` | Latin | Hinglish (code-mixed) | COMI-LINGUA, synthetic (UPI/routing/e-commerce) | Roman script Hindi; only synthetic generation covers this |
| `bn-Beng` | Bengali | Bengali | MASSIVE | MASSIVE test split only in v1 |
| `ta-Taml` | Tamil | Tamil | MASSIVE | MASSIVE test split only in v1 |
| `te-Telu` | Telugu | Telugu | MASSIVE | MASSIVE test split only in v1 |
| `kn-Knda` | Kannada | Kannada | MASSIVE | MASSIVE test split only in v1 |
| `ml-Mlym` | Malayalam | Malayalam | MASSIVE | MASSIVE test split only in v1 |
| `en-Latn` | Latin | English | Banking77, CLINC150 | Used for translated-to-Indic source rows |

## Notes

- Marathi (`mr-Deva`) and Gujarati (`gu-Gujr`) are absent from the MASSIVE mirror used in Phase 1; not included in v1.
- All non-English languages in v1 come from either the MASSIVE official test split (CC BY 4.0) or synthetic data generated by cmul8 (CC BY 4.0).
- Banking77 rows were translated from English to Indic using `facebook/nllb-200-distilled-1.3B`; labels are unchanged by translation.
- Hinglish (`hi-Latn`) data was generated synthetically because NLLB cannot produce Roman-script code-mixed Hindi.
